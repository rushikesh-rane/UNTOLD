# UNTOLD

**Every story has another side.** Read a little. Guess a lot. Discover the truth.

UNTOLD is a suspense-driven social storytelling concept. Readers explore real-life and fictional stories, examine visual details, listen to browser narration, and submit theories before the next reveal.

This repository is the first responsive frontend prototype built with Next.js, React, TypeScript, and CSS. It is intentionally kept small and dependency-light so the product can be validated before adding infrastructure.

## Prototype features

- Editorial, text-first story discovery feed with bold titles
- Search and For you / Trending / New filters
- Dedicated story reader with author details and staged narrative sections
- Image galleries with an enlarged image viewer
- Browser-based narration using the Web Speech API
- Local-session predictions and bookmarks
- Story draft dialog with basic input validation
- Responsive layouts for desktop and mobile
- Metadata for browser titles and social previews

## Current limitations

- Stories, images, theories, and engagement counts are sample content. Images are loaded from Unsplash and need an internet connection.
- Narration depends on speech synthesis support and available voices in the reader's browser/device. It is generated by the browser, not an uploaded audio track.
- Bookmarks and submitted theories are held in client memory; refreshing the page clears them.
- The story form does not publish or persist drafts.
- Authentication, a database, real image/audio uploads, creator following, replies, server-enforced scheduled reveals, notifications, moderation tools, and recommendation ranking are not implemented yet.

## Requirements

- Node.js 20.9 or newer
- npm

## Run locally

From the project folder, run:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run build
```

To run the production build locally:

```bash
npm run start
```

## Suggested next milestone

Connect a managed database and authentication, then implement persisted stories, chapters, predictions, and server-enforced reveal times. Add image/audio uploads and moderation only after the basic story loop is reliable. Keep service keys in environment variables and never commit secrets.


## Authentication gate
All app routes require a signed-in Supabase user except `/login` and `/auth/callback`. Unauthenticated visitors are redirected to `/login` and returned to their requested route after signing in. See `AUTH-UPDATE-INSTRUCTIONS.md`.
